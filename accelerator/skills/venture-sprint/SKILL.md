# Venture Sprint

## Trigger

An approved company task envelope is ready.

## Procedure

1. Verify company tenant, repo/workspace, owner, objective, files/scope, non-goals, done-condition, budget, and rollback.
2. Read company instructions and current state before writing.
3. For code, use one branch/worktree lane; for research, write provenance-bearing records.
4. Execute the smallest slice that creates measurable proof.
5. Run relevant tests, lint, build, or artifact checks.
6. Create a draft PR or internal draft artifact.
7. Route consequential output to Independent Verifier.
8. Record result, cost, evidence, risks, and next proof event.

## Allowed autonomous actions

Internal reversible edits, tests, draft PRs, private experiment plans, internal scorecards, and task creation within the envelope.

## Human gates

Merge, deployment, migration, secrets, permissions, spend, outreach, publication, legal claims, contracts, and destructive operations.

## Stop conditions

Scope drift, tenant mismatch, missing dependency authorization, failed tests after bounded repair, budget overrun, or high/critical risk.

## Output

Draft artifact/PR, verification evidence, handoff, learning record, rollback instructions.
