# Skills

## Skill Inventory

| Skill | Trigger | Output |
|---|---|---|
| Thesis Design | New mandate, fund angle, category focus, or investment lens. | Thesis brief. |
| Opportunity Intake | Raw deal, startup, fund, asset, or partnership notes. | Structured intake. |
| Diligence Queue | Need to decide what to verify next. | Evidence and source checklist. |
| Memo Writing | Need investor or founder-facing synthesis. | Diligence memo. |
| Risk Register | Any opportunity has unclear downside, blockers, or assumptions. | Risk table with owner and status. |
| Portfolio Support | Post-decision or active portfolio help. | 30-day support plan. |
| Investor Update | Need stakeholder communication. | Update brief. |
| Compliance Review | Regulated claims, confidential data, public communication, or decision pressure. | Approval gate note. |

## Skill Quality Bar

Each skill must:

- State its trigger.
- Define inputs.
- Produce one clear artifact.
- Separate evidence from assumptions.
- Name missing information.
- Include approval gates.
- Avoid regulated conclusions.

## Source Order

1. Repo instructions.
2. Registry.
3. Templates.
4. Public-safe examples.
5. Human-provided private context, only when explicitly authorized.
