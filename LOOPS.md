# Loops

## Thesis Loop

```text
market signal -> thesis update -> evidence need -> opportunity filter -> learning
```

## Deal Flow Loop

```text
source -> intake -> qualification -> diligence queue -> decision gate -> archive or support
```

## Diligence Loop

```text
question -> evidence -> confidence -> risk -> open issue -> memo update
```

## Portfolio Support Loop

```text
portfolio need -> support lane -> action -> outcome -> update -> next support
```

## Communication Loop

```text
state -> audience -> update draft -> confidentiality gate -> approval -> send
```

## Memory Loop

```text
memo -> decision -> outcome -> learning -> thesis refinement
```

## Accelerator Loop

```text
application -> evidence -> human decision -> Day-0 OS -> support -> proof -> program learning
```

## Assurance Loop

```text
maker artifact -> independent verifier -> governance gate -> human gate when required -> advance or block
```

## Tenant Learning Loop

```text
company-private result -> approved summary -> anonymization review -> cohort learning candidate -> human-approved benchmark
```
